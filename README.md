# Phiritona Online - Community Chat Platform

A modern, responsive community chat application inspired by the classic Mxit platform. Built with HTML, CSS, and JavaScript, designed to work seamlessly across mobile phones, tablets, and desktop computers.

## 🚀 Features

### Core Functionality
- **User Registration & Login** - Secure account creation and authentication
- **Community Chat Room** - Open public space for all signed-in users
- **Private Messaging** - Direct conversations with other users
- **Real-time Messaging** - Instant message delivery and display
- **Media Sharing** - Support for images, videos, and voice notes
- **Emoji Support** - Rich emoji picker for expressive communication

### User Experience
- **Profile Customization** - Personalized avatars and status messages
- **Privacy Controls** - Visibility settings and user blocking
- **Notifications** - Real-time alerts for new messages and activities
- **Responsive Design** - Optimized for mobile, tablet, and desktop
- **Modern UI** - Clean, intuitive interface with smooth animations

### Technical Features
- **Local Storage** - Persistent user sessions and data
- **Progressive Web App** - App-like experience on mobile devices
- **Voice Recording** - Built-in audio recording for voice messages
- **File Upload** - Easy media sharing with drag-and-drop support
- **Accessibility** - WCAG compliant with keyboard navigation support

## 🎨 Design Theme

- **Primary Color**: Lime Green (#32cd32)
- **Secondary Color**: Black (#000000)
- **Background**: White (#ffffff)
- **Modern Typography**: Inter font family
- **Responsive Layout**: Mobile-first design approach

## 🛠️ Installation & Setup

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional but recommended)

### Quick Start
1. **Download the files**
   ```bash
   # Clone or download the project files
   # Ensure you have: index.html, styles.css, script.js
   ```

2. **Open the application**
   - **Option 1**: Double-click `index.html` to open in your browser
   - **Option 2**: Use a local web server for better performance:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx serve .
     
     # Using PHP
     php -S localhost:8000
     ```

3. **Access the app**
   - Open your browser and go to `http://localhost:8000` (if using a server)
   - Or simply open the `index.html` file directly

### Mobile Installation
1. Open the app in your mobile browser
2. Add to home screen for app-like experience:
   - **iOS**: Tap Share → Add to Home Screen
   - **Android**: Tap Menu → Add to Home Screen

## 📱 Usage Guide

### Getting Started
1. **Registration**: Create a new account with username, email, and password
2. **Login**: Sign in with your credentials
3. **Profile Setup**: Customize your avatar and status message

### Community Chat
- **Send Messages**: Type in the input field and press Enter or click Send
- **Share Media**: Click the + button to share photos, videos, or voice notes
- **Add Emojis**: Click the emoji button to add expressions to your messages
- **View Online Users**: See how many users are currently online

### Private Messaging
- **Start New Chat**: Click "New Chat" and search for users
- **Send Private Messages**: Select a user and start chatting privately
- **Manage Conversations**: View all your private conversations in the chat list

### Profile Management
- **Change Avatar**: Choose from various avatar options
- **Update Status**: Set a custom status message
- **View Account Info**: Check your username, email, and join date

### Privacy & Settings
- **Visibility Control**: Toggle online/offline status
- **Message Settings**: Control who can send you private messages
- **Block Users**: Block unwanted users from contacting you
- **Notifications**: Manage notification preferences

## 🔧 Customization

### Themes
To change the color scheme, modify the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #32cd32; /* Change primary color */
    --secondary-color: #000000; /* Change secondary color */
    --background-color: #ffffff; /* Change background */
}
```
